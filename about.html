About Me

I work in Medtronic for more than 15 years in cardiac and diabetes departments. In many software projects, I participated in development and management from class 1 to class 3 on different platforms.

I used C++ dedicatedly in my first 6 year after graduation. In those years thanks a lot to my colleagues who pushed me to learn C++ thoroughly and built self-study habits.

So far, I worked in many native and hybrid projects from window to mobile, from UI to backend. From those projects, I learned and used different languages (e.g. C/C++, C#, Java, Objective-C, Swift, HTML/JS, SQL and so on. By using different frameworks (e.g. PhoneGap, Xamarin, RxJava, .Net, Angular, Firebase, NodeJS), development environments, and communication protocols, I got well understanding of software architecture and design.

I do enjoy the design and architecture which help more for project than programming language. The design and architecture are the essential of human intelligence which makes complex things simple and clear.

At beginning, when thinking as a software engineer, I thought I was able to implement the feature, no doubt. After years’ practical project experience, I learned how important of team work. A good solution needs to consider regulatory, marketing efficiency, project resource & schedule, human factor, test effort, maintenance, and potential risk. The implementation is very important, but has to make judgment based on many factors.

Besides the software development, I like hiking, nature landscape, reading, handcraft and poem.

C++ is a great language. You can control all details and nothing is hidden. Although you are in charge of each byte of memory, you get the good control of the performance. C++ 17 is in progress now. Both iOS and Android platform supports C++ well. Sadly it is not as popular as before. (Partially because of shorter and shorter delivery cycle.)

C#, Java, kotlin are good tools for rapid development. Both of them can be compiled into native code for the target platform now to gain good performance. User/Client still needs to pay more extra memory for them. MS open source the .NET framework, acquired Xamarin and enabled Visual Studio for Android/iOS. There is bright future of C#.
